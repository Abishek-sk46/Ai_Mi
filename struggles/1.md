# Debugging Journal

## Date

December 2025

## Project

AI_MI

## Problem

Inngest functions were failing to register.

### Symptoms

* `PUT /api/inngest 400`
* `sdk_version_denied`
* `Cannot read properties of undefined (reading 'step')`
* Function registration failed.
* App accepted prompts but agents never executed.

---

## Root Cause

### Issue 1: SDK Version Blocked

My project was using:

* Inngest: `3.32.5`
* Agent Kit: `0.8.3`

The Inngest server rejected the old SDK version because it contained a security vulnerability.

Error:

sdk_version_denied

### Fix

Upgraded Inngest SDK to a newer supported version.

---

## New Problem After Upgrade

After upgrading, function registration worked but agent execution crashed.

Error:

TypeError: Cannot read properties of undefined (reading 'step')

---

## Root Cause

Agent Kit was built expecting:

```ts
ctx.step
```

Newer Inngest SDK exposed:

```ts
execution.ctx.step
```

Agent Kit looked for `ctx.step`, found `undefined`, and crashed.

---

## Fix

Added a compatibility patch that maps:

```ts
execution.ctx.step
```

to

```ts
ctx.step
```

This acted as a bridge between the old Agent Kit and the newer Inngest SDK.

---

## Lessons Learned

1. Updating a package can fix one issue and create another.
2. Uninstalling and reinstalling does not solve API compatibility problems.
3. Libraries that depend on each other must use compatible versions.
4. Read changelogs before upgrading major packages.
5. Version conflicts are common in professional development.
6. Debugging dependency issues is an important engineering skill.

---

## Mental Model

```text
My App
   ↓
Agent Kit
   ↓
Inngest SDK
   ↓
Inngest Server
```

If any layer changes its API, the layers above it may break.

---

## Future Checklist

When facing package issues:

□ Check package versions

□ Check changelog

□ Check GitHub issues

□ Check peer dependencies

□ Create a minimal reproduction

□ Verify compatibility matrix

□ Look for breaking changes

□ Test with older working version

□ Test with latest version

□ Compare APIs between versions
